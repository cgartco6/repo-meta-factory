# ⚙️ FastAPI Asynchronous Agency Orchestration Core

This service layer encapsulates our isolated agency studios into decentralized, standalone Python apps running async REST architectures.

## 📁 Workspace Layout
- `/core_orchestrator`: Core routing protocols, authentication handlers, and HITL webhook systems.
- `/branding_studio`: High-tier strategy calculation models utilizing external cloud intelligence.
- `/design_studio`: Image layout generation piping into serverless GPU endpoints (FLUX/Replicate).
- `/marketing_studio`: Social copy variants creation pipelines and platform scheduling mocks.
